KAIROS SYSTEM - это мощная консольная утилита для комплексной диагностики, мониторинга и обслуживания компьютеров под управлением Windows. Программа объединяет в себе десятки инструментов администрирования в едином интерактивном меню с удобной навигацией по клавишам.

🚀 Возможности

◆ Система
Информация о компьютере, ОС, процессоре, ОЗУ, накопителях

Сведения о видеокарте, материнской плате и BIOS

◆ Устройства
Сеть, питание, мониторы, периферия USB

Звуковые устройства, батарея/ИБП, датчики, принтеры

◆ Безопасность
Проверка антивируса / Microsoft Defender

Состояние брандмауэра и SMART-дисков

Просмотр журнала событий и статуса BitLocker

◆ Производительность
Нагрузка в реальном времени

Индекс производительности WinSAT

Топ процессов

Анализ .jar-файлов

◆ Софт и сервисы
Проверка активации Windows

Список установленного ПО и обновлений

Драйверы, службы, автозагрузка

Пользователи и точки восстановления

◆ Сеть
Wi-Fi сети и сохранённые пароли

Открытые порты и активные соединения

Конфигурация VPN и прокси

◆ Утилиты
V - активация Windows и Office

K - очистка ненужных файлов

A - полный отчёт по всем разделам

E - экспорт данных в CSV / JSON / HTML

C - сравнение с предыдущим отчётом

D - автоматическая диагностика проблем

H - встроенная справка

R - перезапуск с правами администратора

◆ Развлечения
🐍 Классическая игра «Змейка» прямо в консоли

🖥️ Интерфейс
Программа использует псевдографический интерфейс с рамками и разделами, что делает навигацию интуитивной даже в командной строке. Все действия выполняются через ввод соответствующей цифры или буквы.

⚙️ Требования
ОС: Windows 10 / Windows 11

Права: рекомендуется запуск от имени администратора (клавиша R)

Среда: PowerShell / Windows Terminal

🎯 Для кого этот инструмент
Системные администраторы — быстрая диагностика парка ПК

IT-специалисты — сбор отчётов и сравнение конфигураций

Продвинутые пользователи — мониторинг и обслуживание своей системы

Энтузиасты — изучение внутренностей Windows в удобной форме
